# حذف ورودی‌های DashboardScreen

سازندهٔ `DashboardScreen` و `DashboardHomePanel` فقط `super.key` دارد. دریافت repository، تنظیمات و callbackهای والد از این دو ویجت حذف شد.

## مالکیت داده و تعامل‌ها

- route خانه، `HomeCubit` را با `DashboardRepositories` موجود در composition برنامه می‌سازد و بارگذاری چهار تب را آغاز می‌کند. پایان عمر route، Cubit را می‌بندد.
- انتخاب تب، علاقه‌مندی‌ها، درخواست سرویس، متن ارسال‌شده و درخواست‌های منو، اعلان، پروفایل و دیالوگ‌ها با اکشن‌های Home مدیریت می‌شوند.
- `BlocBuilder` دادهٔ State را نمایش می‌دهد. `BlocListener` اجرای مسیریابی، clipboard و sheet را بر عهده دارد. FocusNode همچنان منبع متعلق به چرخهٔ عمر UI است.
- درخواست‌های کارت و سپرده هنگام مسیریابی، اطلاعات رکورد انتخاب‌شده را حفظ می‌کنند. callbackهای UI در Cubit ذخیره نمی‌شوند.
- برای قابلیت‌های فاقد مقصد، backend دستیار و ذخیرهٔ دائمی علاقه‌مندی‌ها، پیاده‌سازی جدیدی ساخته نشده است. متن prompt در State ثبت می‌شود.

## اعتبارسنجی

تست‌ها به تزریق Cubit در محیط تست و مشاهدهٔ State/Effect منتقل شدند؛ سازندهٔ production برای تست پارامتر اضافه ندارد. سناریوهای prompt خالی و تکراری، بازگشت دستیار به خانه، محدودبودن picker/reset به ویرایش فعال و مسیریابی واقعی سرویس‌ها بررسی می‌شوند.

- اجرای کامل `flutter test --no-pub`: هر ۳۵۰ تست موفق بود.
- تحلیل Dart برای Dashboard، router و تست‌های وابسته: بدون خطا و هشدار.
- بررسی `git diff --check`: موفق.
